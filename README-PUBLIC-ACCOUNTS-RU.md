# HoodakMail — публичные аккаунты

## Что добавлено

- самостоятельная регистрация на странице входа;
- постоянный адрес `логин@hoodak-team.lol`;
- автоматический вход сразу после регистрации;
- вход по короткому логину или полному адресу;
- отдельный личный кабинет обычного пользователя;
- доступ пользователя только к собственному ящику и письмам;
- один ящик на новый аккаунт;
- защищённое хранение новых паролей через PBKDF2-SHA256 с уникальной солью;
- совместимость со старыми SHA-256 паролями;
- лимит: не более пяти попыток регистрации с одного IP за час;
- запрет служебных имён: admin, support, postmaster, abuse и другие;
- опциональная защита Cloudflare Turnstile;
- администраторский аккаунт и существующие ящики сохранены.

## Как установить через GitHub

1. Создайте резервную копию текущего репозитория или отдельную ветку.
2. Распакуйте `hoodakmail-public-accounts.zip`.
3. Загрузите содержимое папки `hoodak-mail-main` в корень репозитория `coolertema/hoodak-mail` с заменой файлов.
4. Сделайте commit и push. Cloudflare запустит новую сборку автоматически.
5. Дождитесь зелёного статуса Build и Deploy.
6. Откройте `/login` в режиме инкогнито — рядом со входом появится вкладка «Регистрация».

Таблица ограничения регистраций создаётся Worker автоматически при первом запросе. Обновлённый `d1-init.sql` также содержит её для новых установок.

## Обязательные Runtime variables / Secrets

Существующие значения должны остаться:

- `MAIL_DOMAIN = hoodak-team.lol`
- `ADMIN_NAME = hoodakadmin`
- `ADMIN_PASSWORD` — Secret
- `JWT_TOKEN` — Secret

Для включения регистрации:

- `PUBLIC_SIGNUP_ENABLED = 1`

Чтобы временно закрыть регистрацию, установите:

- `PUBLIC_SIGNUP_ENABLED = 0`

## Рекомендуется: Cloudflare Turnstile

1. Cloudflare Dashboard → Turnstile → Add widget.
2. Добавьте hostname `mail.hoodak-team.lol`.
3. Скопируйте Site key и Secret key.
4. В Worker → Settings → Variables and Secrets добавьте:
   - `TURNSTILE_SITE_KEY` как обычную переменную;
   - `TURNSTILE_SECRET_KEY` как Secret.
5. Выполните новый Deploy.

Если ключи Turnstile не указаны, регистрация всё равно работает и защищена серверным rate limit. Перед публичным запуском Turnstile желательно включить.

## Проверка

1. Откройте `https://mail.hoodak-team.lol/login` в режиме инкогнито.
2. Выберите «Регистрация».
3. Создайте, например, `testuser@hoodak-team.lol`.
4. Пароль должен содержать минимум 8 символов, букву и цифру.
5. После регистрации откроется личный кабинет.
6. Отправьте письмо на созданный адрес и проверьте раздел «Входящие».
7. Выйдите и войдите снова — можно вводить `testuser` или полный адрес.

## Ограничение текущей версии

Новые пользовательские аккаунты предназначены прежде всего для получения писем через веб-интерфейс. Исходящая отправка для них отключена, чтобы защитить домен от спама и ухудшения репутации.
